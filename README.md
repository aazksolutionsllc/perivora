Deploy, manage, and scale enterprise AI on your infrastructure with complete data privacy, enterprise security, and full operational control.

## 🎨 Design Theme

- **Base background**: Deep navy (#0A2239)
- **Primary accent**: Deep tech blue (#005F9E)
- **Secondary accent**: Bright teal (#38B0C0)
- **Font**: Inter (modern sans-serif)

The design is clean, futuristic, minimal, and intelligent with subtle motion and gradient depth.

## 🚀 Getting Started

### Prerequisites

- Node.js 16+ and npm

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser to [http://localhost:5173](http://localhost:5173)

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.
